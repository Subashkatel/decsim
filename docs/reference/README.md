# Reference

Reference pages state what the pieces are, so that you can look a thing
up while you work.

- [The parts](parts.md): every settings record a machine is built from,
  with its fields and their defaults. Generated from the source by
  `tools/docs_map.py` and checked by `tests/test_docs.py`.
- [The run folder](run_folder.md): every file a run writes, every
  column of every csv, and the latency points.
- [Glossary](glossary.md): what the code calls a thing, what the papers
  call it, and where in the papers to read it.
