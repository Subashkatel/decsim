# The commands

This page is generated by `tools/docs_map.py` and checked by `tests/test_docs.py`. To change it, change the source it reads and run the tool again.

`decsim <verb>`: the command set, dispatched on the first word.

Every argument below is read from the `argparse` definition that parses it. An argument with no default is required.

## `decsim collect`

| Argument | Default | What it is |
| --- | --- | --- |
| `config` | required | the experiment yaml to sweep |
| `--out` | None | the run folder to write |
| `--processes` | 1 | worker processes, one task each (shots stay serial) |
| `--shard` | None | i/n: run the work units whose index modulo n is i |
| `--shots-per-unit` | None | split a point's seeds into work units of this many |

## `decsim combine`

| Argument | Default | What it is |
| --- | --- | --- |
| `run_dirs` | required | the folders to fold |
| `--out` | None | the folder the combined rows go in |

## `decsim plot`

| Argument | Default | What it is |
| --- | --- | --- |
| `run_dirs` | required | the folders to read |
| `--figure` | 'timeline' | which figure to draw |
| `--out` | None | where the figure goes |
| `--probability` | None | the physical error rate the ler_vs_d figure is drawn at |

## `decsim run`

| Argument | Default | What it is |
| --- | --- | --- |
| `config` | required | the experiment yaml to run |
| `--seed` | 0 | the shot's seed (default 0) |
| `--out` | None | the folder the log and trace go in |
| `--log` | None | the engine narrator, overriding the yaml for this run |
| `--trace` | off unless the flag is given | write this shot's Chrome trace of the data path |

## `decsim show`

| Argument | Default | What it is |
| --- | --- | --- |
| `config` | required | the experiment yaml to resolve |

## `decsim trace`

| Argument | Default | What it is |
| --- | --- | --- |
| `action` | required | follow: one thing's path |
| `file` | required | the trace file one shot wrote |
| `--round` | None | the round, as op:index |
| `--window` | None | the window, as op:id |
| `--html` | None | write the page here |
