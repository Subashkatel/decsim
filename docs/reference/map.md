# The map of the package

This page is generated by `tools/docs_map.py` and checked by `tests/test_docs.py`. To change it, change the source it reads and run the tool again.

Every module of `decsim/`, grouped by the package it belongs to
and ordered by the level that package sits on. A package on
level 0 imports no other `decsim` package. A package on level n
imports one on level n minus one and none above it, so the
levels above any line can be cut away and what is left still
runs. The levels are the ones `tools/check_uses_graph.py`
prints and `decsim/machine.py` names in its docstring. Each
line is a module's path and the first sentence of its
docstring.

## The package root

- `decsim/__init__.py`: decsim, a discrete-event simulator of the QEC reaction path.

## Level 0: config, records, tables, trace_source

### config

- `decsim/config.py`: The tick, and the clock domains a yaml prices its cycles on.

### records

- `decsim/records/__init__.py`: The vocabulary every component speaks, one module per record family.
- `decsim/records/decoder_evidence.py`: The evidence a decode returns beside its correction, for a signal to read.
- `decsim/records/decoding.py`: One decode: the job, the result, and the holds that keep its rounds.
- `decsim/records/identity.py`: What decsim accepts as an operation, patch or window key.
- `decsim/records/log_sources.py`: The name each component narrates under, in one place.
- `decsim/records/program.py`: The program the front end hands the machine, one operation at a time.
- `decsim/records/results.py`: The records one run returns: the run and each logical operation.
- `decsim/records/rounds.py`: One syndrome round on its way out of the QPU and through the controller.
- `decsim/records/seeds.py`: The run-level seed graph's records: a path edge, a child, a reservation.
- `decsim/records/transfers.py`: One transfer on one link: its hop, its bits, its timing, its ledger.
- `decsim/records/windows.py`: One decoder window: its geometry, its plan, its boundaries, its state.

### tables

- `decsim/tables.py`: The plug-in tables' lookup: a name, a row, or a refusal that lists them.

### trace_source

- `decsim/trace_source.py`: A trace source: one named event a component fires and listeners hear.

### links
