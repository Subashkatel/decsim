# Parts

This page is generated by `tools/docs_map.py` and checked by `tests/test_docs.py`. To change it, change the source it reads and run the tool again.

A machine is one `MachineSettings` (`decsim/settings.py`), a record of records: each field holds the settings of one part, and a part's record holds the records of the components it builds. A record with a `build` method builds its component. A field with no default is required, and a field's unit is in its name.
