# The ports

This page is generated by `tools/docs_map.py` and checked by `tests/test_docs.py`. To change it, change the source it reads and run the tool again.

The ports: the map of a readout's path through the machine.

The headings are the port file's own section banners, so this page reads in the order `decsim/ports.py` reads: the order a readout travels.
